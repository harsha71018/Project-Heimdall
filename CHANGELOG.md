# Changelog

All notable changes to Project Heimdall will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-10-21

### Added
- **Hidden Provenance Stamps (`_sync_stamp`)**: Workbooks generated by `generate()` now embed a hidden sheet recording initial status/notes. Human edits in dated `leads/*.xlsx` archives are now reliably distinguished from stale baseline values and preserved across subsequent runs without weakening primary tracker precedence.
- **Shared URL Utilities (`url_utils.py`)**: Extracted `canonicalize_job_url` and `IDENTITY_QUERY_PARAMS` into a single module, imported by both `scraper.py` and `excel_generator.py` to prevent ledger key divergence.
- **Windows-Safe Atomic Run Lock (`heimdall.lock`)**: Prevents race conditions between manual runs and Windows Task Scheduler using `os.O_CREAT | os.O_EXCL` with a 30-minute staleness timeout.
- **Dynamic Firecrawl Lookback Mapping**: Configured `search.hours_old` is now mapped via `_tbs_for_hours()` to Firecrawl search tokens (`qdr:d`, `qdr:w`, `qdr:m`, `qdr:y`) instead of hardcoding past-week filtering.
- **Unlisted Host Telemetry**: Added `dropped_unlisted_host` counter across Firecrawl and JobSpy collection paths to make funnel filtering math completely explainable in the Run Summary.
- **CLI Ergonomics**: Added `--mode deep` as a native alias for `--mode exhaustive`.
- **Empty Config Crash Guard**: Bulletproofed `load_config()` to return `{}` on empty 0-byte YAML files.
- **Automated CI Workflow**: GitHub Actions matrix workflow verifying all 44 unit tests across Python 3.10, 3.11, 3.12, and 3.13.
- **MIT License**: Added official MIT License file and copyright notice.

### Fixed
- **Archive Status Retention (Bug B1)**: Resolved silent loss of application status edits made inside dated `leads/` spreadsheets.
- **Compact Naukri Experience Slugs (Bug B3)**: Widened regex to parse `-0-2-years-` in addition to `-0-to-2-years-`, preventing company name corruption.
- **Title Fresher Marker Preservation (Bug B4)**: Preserved fresher markers when titles are structured as `"Data Analyst - Fresher - Company"`.
- **Telemetry Schema Migration (Bug B8)**: Added `jobspy_candidates` to `RUN_LOG_HEADERS` (14-column header) with full backward-compatibility for legacy 7, 8, and 13-column schemas.
- **Dependency Hygiene**: Upgraded `python-jobspy>=1.3.0` (verified 1.4.0), removed unneeded transitive dependencies (`tls-client`, `markdownify`, `pydantic`), and verified compatibility with `pandas 3.0.x` and `numpy 2.5.x`.
- **Method Encapsulation**: Exposed public `save_seen_jobs()` on `MultiPlatformJobScraper` (maintaining `_save_seen_jobs` alias for backward compatibility) and removed dead logger.

### Security
- Added `*.html` to `.gitignore` to prevent accidental public disclosure of personal resume files.
- Added comprehensive disclaimer on platform Terms of Service, personal-use bounds, and cloud query privacy.
